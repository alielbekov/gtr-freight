# GTR Freight — static website

Static HTML/CSS/JS site built from the Figma design "GTR website".
No build step: every page is a plain `.html` file at the project root.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `about.html` | About us |
| `team.html` | Our team |
| `careers.html` | Careers |
| `contacts.html` | Contacts (message form) |
| `freight-brokerage.html` | Freight brokerage |
| `managed-transportation.html` | Managed transportation |
| `warehousing.html` | Warehousing and Fulfillment |
| `cross-border.html` | Cross-Border Logistics |
| `ship-international.html` | Ship international (quote form) |
| `become-shipper.html` | Become a shipper (onboarding form) |
| `become-carrier.html` | Become a carrier |

Shared files: `css/style.css`, `js/main.js`, images in `assets/img/`.

The HTML files are generated by `tools/build_site.py` (shared header, footer,
CTA and testimonial blocks plus each page's content). Edit that script and run
`python3 tools/build_site.py .` from the project root to regenerate all pages,
or edit the `.html` files directly if you prefer.

## Run locally

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Deploy on Coolify

The repo contains a `Dockerfile` (nginx:alpine) and `nginx.conf`.

1. Push this folder to a Git repository.
2. In Coolify: **New resource → Application → your repo**, build pack **Dockerfile**.
3. Expose port **80** and attach your domain. Nothing else to configure.

`nginx.conf` serves clean URLs (`/about` → `about.html`), gzips text assets
and sets long cache headers for images, CSS and JS.

Alternatively use Coolify's **Static** build pack with the publish directory
set to `/` — the site works without the Dockerfile too.

## Forms

The three forms (Contacts, Ship international, Become a shipper) are static:
on submit they validate and show a confirmation message, nothing is sent.
To collect submissions, point each `<form>` `action` at a form backend
(Formspree, Basin, your own API, ...) and remove the `data-static` attribute.
